📖 使用指南：來不及看盤如何及時買賣

核心思路：機器盯盤、人只在盤前準備＋收到推播後 30 秒決策。每天約 20 分鐘人工。

每日流程

  1. 盤前 6:30 前（規則 #36/#37）：掃描器篩「缺口>4% + Float<10M + RVOL>5x」→ 在下方「層一」輸入候選股自動評分，只留 4/5、5/5。
  2. 掛條件單：「層三」計算器算出 OCO 括號單（入場 Buy Stop-Limit＋止損 Sell Stop＋分批止盈），盤前掛入券商後即使不看盤也會自動執行。
  3. 盤中只處理推播：TradingView 設好下方三支 Pine 腳本的警報。收到「MACD 轉紅燈」「放量跌破 VWAP」推播才需要手動處理。
  4. 風控自動化：達日最大虧損強制停止（#47）、峰值回吐 50% 收工（#48）— 層三會自動亮紅燈。

自動化三個層級

  • 半自動（建議起點）：盤前掛 OCO 括號單，警報只做否決用。
  • 警報驅動：推播 → 券商 App 一鍵下單（預設倉位模板）。
  • 全自動：TradingView Webhook → Alpaca/IBKR API 下單；務必先模擬盤一個月，並把冷市縮倉（#33/#34）與熔斷做進程式。

買入訊號特徵摘要

  • 入市① Gap & Go：破盤前高 1–2 美分；量>5x、MACD 綠燈、價>VWAP、9:30–9:45 窗口；止損＝突破K線低點（#10/#24/#30/#68）
  • 入市② Bull Flag 首次回踩：回踩<前波20%、回踩量<突破量50%、有下影線、守住EMA9，首根創新高K線進場；止損＝旗形低點（#13/#15）

賣出訊號特徵摘要

  • 延伸棒長上影＋離VWAP>10% → 減半倉（#3/#60）；整數關口/第二延伸棒 → 再減半（#53）
  • 放量跌破旗形低點＋MACD轉負 → 全部出清（#16/#24）；高點回落>20% 即 Back-side 不再做多（#76）

📣 TradingView Pine 警報腳本（v5）

展開 → 複製 → 貼到 TradingView Pine Editor → 加入圖表 → 在「警報」對話框選取對應 alertcondition，通知勾選 App 推播。
bull_flag_first_pullback.pine 
//@version=5
// Bull Flag 首次回踩突破警報 (入市② 訊號)
// 對應規則: #13 首次回踩勝率最高 / #15 Mini Pullback 精確識別 / #16 Dump 識別
// 邏輯: 偵測「放量急拉 -> 縮量淺回踩(未破前波20%) -> 首根創新高K線」
indicator("Ross Bull Flag First Pullback", overlay = true)

surgeLen   = input.int(5,    "急拉判定K線數")
surgePct   = input.float(5,  "急拉最小漲幅 %", minval = 1)
maxRetrace = input.float(30, "最大回踩比例 % (>30%=Dump)", minval = 5)
pullVolPct = input.float(50, "回踩量須低於突破量的 %")

[macdLine, _, _] = ta.macd(close, 12, 26, 9)

// ---- 狀態機: 0=找急拉  1=回踩中  ----
var int   st        = 0
var float waveLo    = na   // 波段起點
var float waveHi    = na   // 波段高點
var float surgeVol  = na   // 急拉期間最大量
var int   pullBars  = 0

surge = (close - low[surgeLen]) / low[surgeLen] * 100 >= surgePct and
        volume > ta.sma(volume, 20) * 3

if st == 0 and surge
    st       := 1
    waveLo   := low[surgeLen]
    waveHi   := high
    surgeVol := volume
    pullBars := 0

flagBreak = false
if st == 1
    waveHi   := math.max(waveHi, high)
    surgeVol := math.max(surgeVol, volume)
    retrace   = (waveHi - low) / (waveHi - waveLo) * 100
    pullBars += close < waveHi ? 1 : 0
    // Dump 條件: 回踩過深 / 放量下殺 / MACD 轉負 (#16) -> 放棄
    if retrace > maxRetrace or macdLine < 0
        st := 0
    // 首次回踩後第一根創新高 K 線 = 入場 (#13/#15)
    else if pullBars >= 2 and close > waveHi[1] and
            volume[1] < surgeVol * pullVolPct / 100
        flagBreak := true
        st := 0

plotshape(flagBreak, "FlagBreak", shape.triangleup, location.belowbar,
          color.teal, size = size.small, text = "FLAG")

alertcondition(flagBreak, "Bull Flag 首次回踩突破",
     "{{ticker}} 首次縮量回踩後創新高 {{close}} — Bull Flag 入場. 止損=旗形低點")
gap_and_go_alert.pine 
//@version=5
// Gap & Go 突破警報：破盤前高 + 爆量 + MACD綠燈 (入市① 訊號)
// 對應規則: #10 Gap&Go / #30 黃金15分鐘 / #68 無量突破不追 / #24 MACD綠燈
// 用法: 加到 1 分鐘圖 (需開啟盤前數據 Extended Hours)，對觀察清單每隻股各設一個警報
indicator("Ross Gap & Go Alert", overlay = true)

volMult   = input.float(5.0, "突破量能倍數", minval = 1)
volAvgLen = input.int(20, "平均量週期")
onlyGold  = input.bool(true, "只在 9:30–9:45 黃金窗口觸發")

// ---- 盤前高點 (04:00–09:30 ET) ----
inPre = not session.ismarket
var float pmHigh = na
if session.isfirstbar_regular
    pmHigh := pmHigh                       // 開盤時凍結
if inPre
    pmHigh := na(pmHigh) ? high : math.max(pmHigh, high)
if session.islastbar_regular
    pmHigh := na                            // 收盤後重置

plot(session.ismarket ? pmHigh : na, "盤前高點", color.gray,
     2, plot.style_linebr)

// ---- 條件 ----
[macdLine, _, _] = ta.macd(close, 12, 26, 9)
rvol    = volume / ta.sma(volume, volAvgLen)
tGold   = time(timeframe.period, "0930-0945", "America/New_York")
inGold  = not onlyGold or not na(tGold)

gapGo = session.ismarket and not na(pmHigh) and
        ta.crossover(close, pmHigh) and
        rvol >= volMult and macdLine > 0 and inGold

plotshape(gapGo, "GapGo", shape.triangleup, location.belowbar,
          color.blue, size = size.small, text = "GO")

alertcondition(gapGo, "Gap&Go 突破盤前高",
     "{{ticker}} 突破盤前高 {{close}}, 爆量+MACD綠燈 — Gap&Go 入場訊號. 止損=突破K線低點")
ross_momentum_dashboard.pine 
//@version=5
// Ross Momentum 主指標：VWAP + EMA9/20 + MACD 紅綠燈背景 + RVOL 警報
// 對應規則: #2 VWAP動態支撐 / #24 MACD綠燈紅燈 / #26 均線排列 / #68 無量突破不追
// 用法: 貼到 TradingView Pine Editor -> 加到 1 分鐘圖 -> 右上角「警報」選本指標的 alert 條件
indicator("Ross Momentum Dashboard", overlay = true)

// ---- 參數 ----
volMultBreak = input.float(5.0,  "突破量能倍數 (RVOL)", minval = 1)
volMultDump  = input.float(3.0,  "跌破VWAP放量倍數",   minval = 1)
volAvgLen    = input.int(20,     "平均量週期")

// ---- 指標 ----
vwapLine = ta.vwap
ema9  = ta.ema(close, 9)
ema20 = ta.ema(close, 20)
[macdLine, sigLine, histLine] = ta.macd(close, 12, 26, 9)
avgVol = ta.sma(volume, volAvgLen)
rvol   = volume / avgVol

plot(vwapLine, "VWAP",   color = color.purple, linewidth = 2)
plot(ema9,     "EMA 9",  color = color.orange)
plot(ema20,    "EMA 20", color = color.blue)

// MACD 紅綠燈背景 (#24: 綠燈才可做多; 紅燈禁止做多)
bgcolor(macdLine > 0 ? color.new(color.green, 92) : color.new(color.red, 94),
        title = "MACD 紅綠燈")

// ---- 訊號 ----
// 1) VWAP 站穩再突破 (#2)
holdVwap  = close > vwapLine and low <= vwapLine        // 回踩VWAP收上
// 2) 放量跌破 VWAP = 止損/趨勢反轉 (#2)
breakVwap = ta.crossunder(close, vwapLine) and rvol >= volMultDump
// 3) MACD 轉燈 (#24)
greenOn   = ta.crossover(macdLine, 0)
redOn     = ta.crossunder(macdLine, 0)
// 4) 均線多頭排列成立 (#26)
bullStack = ema9 > ema20 and close > ema9

plotshape(holdVwap and macdLine > 0, "VWAP站穩", shape.triangleup,
          location.belowbar, color.green, size = size.tiny, text = "VWAP")
plotshape(breakVwap, "放量跌破VWAP", shape.triangledown,
          location.abovebar, color.red, size = size.tiny, text = "DUMP")

// ---- 警報 ----
alertcondition(holdVwap and macdLine > 0 and rvol >= 2,
     "VWAP站穩+綠燈", "{{ticker}} 回踩VWAP站穩 + MACD綠燈, RVOL={{volume}}")
alertcondition(breakVwap, "放量跌破VWAP(止損)", "{{ticker}} 放量跌破VWAP — 止損/不再做多")
alertcondition(greenOn, "MACD轉綠燈", "{{ticker}} MACD 轉正 — 可以評估做多")
alertcondition(redOn,   "MACD轉紅燈", "{{ticker}} MACD 轉負 — 禁止做多, 持倉考慮出場")
