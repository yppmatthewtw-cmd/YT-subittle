# XTrader 猫姐美股 —「價格以外的第二維度」推論與 Pine 重建可行性

> 目的：猜測猫姐用來判斷個股「上昇 / 下跌最低阻力線」的兩個非價格指標——**價格重心**、**買賣力度**——
> 最可能的計算參數，並評估能否用 Pine Script 在 TradingView 重建。
> 本文件是**推論**，不是她的原始公式（她的「笨猫系統 / 禪動買賣點」是俱樂部付費指標，未公開原始碼）。

## 2. 「價格重心」最可能是什麼

在中文技術分析語境裡，「重心」幾乎固定指 **成交量加權的平均成本**（籌碼分佈的黃線 = 「籌碼重心」＝所有持倉者的加權均價），
再配合她「主力資金 / 定錨 / 穩定」的用語，最合理的推論是：

```
價格重心 ≈ 某個錨定區間內的 成交量加權均價 (VWAP)          ← 時間維度
        或 該區間 成交量分佈的最大量價位 (POC)              ← 價格維度
判斷的不是重心的絕對值，而是：
  ① 重心的斜率（上移 / 走平 / 下移）→ 主力成本往哪走 = 最低阻力方向
  ② 重心的穩定度（N 根內位移 / ATR）→ 穩定 = 主力沒走、可定錨
  ③ 價格與重心的距離（以 ATR 或 σ 計）→ 偏離太遠會回歸、貼近則是防守位
  ④ 價格假跌破重心又收回 → 「用股價打掩護」的洗盤
```

**猜測的參數（按可能性排序）**

| 參數 | 猜測值 | 理由 |
|---|---|---|
| 錨定方式 | 日內：當日 VWAP；波段：週 / 月錨定 VWAP，或滾動 N 根 | 她同時做日內與波段，兩種都會用 |
| 滾動長度 N | 20–60 根（日線）；日內用當日 | 對應「大半年第一次」這種長週期比較，另有更長的參考 |
| 穩定度窗口 M | 5 根（與「滯後 5 根 K」一致） | 她公開接受 5 根確認 |
| 距離單位 | ATR(14) 或成交量加權 σ | 跨股票可比 |
| 價格來源 | hlc3 或 close | VWAP 慣例 |

## 3. 「買賣力度」最可能是什麼

「力度 / 力道」在中文量價指標裡是 **主動買 vs 主動賣的成交量對比**（內外盤、主買佔比、資金淨流入）。
她的「結構低點 / 無結構低點」「主力五次防守」「用股價打掩護」都指向同一件事：**價格創新低時，買力有沒有進來承接**。

```
買賣力度 ≈ (主動買量 − 主動賣量) / 總量           ← −1 … +1，可再平滑
累積力度 ≈ Σ(主動買量 − 主動賣量)  自當日開盤 / 自某錨點起   ← 類似 CVD
結構低點   = 價格新低，但買賣力度 / 累積力度 沒有新低（買力背馳、主力承接）
無結構低點 = 價格新低，力度也同步新低（無承接、賣壓一次出清 → 常是最後一跌）
主力防守位 = 同一價位被多次觸及，每次觸及時力度都轉正
```

**猜測的參數**

| 參數 | 猜測值 | 理由 |
|---|---|---|
| 分類主動買 / 賣的資料 | 逐筆或 1 分鐘 K（她有數據公司，可能用逐筆；公開版以 1 分鐘近似即可） | 「2:05pm 觸發」= 分鐘級 |
| 平滑 | EMA 3–5 | 「結構低點長達一小時」= 需要一段時間才確認，不是單根 |
| 比較窗口 | 日內：當日；日線：20 根 | 與重心一致 |
| 大單門檻 | 單根量 ≥ 2–3 × 平均單根量 | 「主力進場 / 出貨」 |

## 4. 能否用 Pine Script 重建

| 項目 | 可行度 | 說明 |
|---|---|---|
| 價格重心（VWAP / 錨定 VWAP / 滾動 VWAP） | ✅ 完全可行 | `ta.vwap(src, anchor)`、`math.sum(src*vol)/math.sum(vol)` |
| 價格重心（POC 成交量分佈） | ✅ 可行 | 自行分箱累積，N=120、40 箱每根約 5k 次運算，沒問題 |
| 重心斜率 / 穩定度 / 距離 | ✅ 完全可行 | 純數學 |
| 買賣力度（1 分鐘近似主動買賣） | ✅ 可行，有限制 | `request.security_lower_tf` 可拿到每根 K 內的 1 分鐘明細；上限 100,000 根分鐘 K ≈ 日線 250 天、5 分鐘圖約 1 年 |
| 買賣力度（逐筆 / Level-2 內外盤） | ❌ 不可行 | Pine 沒有逐筆與掛單簿資料；只能用 K 線收在區間的位置近似 |
| 結構 / 無結構低點、主力防守位 | ✅ 可行 | 用「價格新低 vs 力度新低」的背馳邏輯 + 轉折確認 |
| 即時「2:05pm 觸發」警報 | ✅ 可行 | `alertcondition` 或 `alert()` |

**結論：** 除了逐筆內外盤，兩個維度都能在 TradingView 用 Pine 做出**功能等價**的版本；
差別只在資料粒度（1 分鐘 vs 逐筆），對日線與 5–15 分鐘圖的判斷影響不大。

## 5. 本目錄的 Pine 原型

| 檔案 | Pane | 內容 |
|---|---|---|
| `pine/maojie_price_gravity.pine` | 主圖 | 三種重心（當日 / 錨定 / 滾動 VWAP，或 POC）＋ 成本帶 ± kσ ＋ 重心斜率、穩定度、價格距離 ＋ 上移 / 下移 / 定錨 / 假跌破 訊號 ＋ 右側資訊框 ＋ 警報 |
| `pine/maojie_buy_sell_force.pine` | 下方 pane | 以 1 分鐘（可調）近似主動買賣量 → 淨力度柱、平滑力度線、當日 / 滾動累積力度 ＋ 結構低點 / 無結構低點 / 結構高點 ＋ 主力防守位計數 ＋ 大單淨額 ＋ 資訊框 ＋ 警報 |

兩支腳本的資訊框沿用 R5/R6 的「⑦ 版面」規則（`boxW` 同值即等寬貼右）。
